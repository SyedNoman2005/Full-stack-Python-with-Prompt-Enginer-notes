				======================================================================
							Operations on Series Object Part-1
				======================================================================
0. Adding new Value to the Series Object

1. Adding the Values of Series Object (Sum)
			Syntax1: SeriesObject3=SeriesObj1.add(SeriesObj2)
			Syntax2: SeriesObject3=SeriesObj1.add(SeriesObj2,fill_value=0)

2. Substracting the Values of Series Object:
			Syntax1: SeriesObject3=SeriesObj1.sub(SeriesObj2)
			Syntax2: SeriesObject3=SeriesObj1.sub(SeriesObj2,fill_value=0)

3. Droping the Values of Series Object
			Syntax1: SeriesObject.drop([Index])  # here default inplace value is False
			Syntax2: SeriesObject.drop([Label Name])  # here default inplace value is False
			Syntax3: SeriesObject.drop([Index1,Index2,...,Index-n])   # here default inplace value is False
			Syntax3: SeriesObject.drop([Label1,label2,...,label-n])    # here default inplace value is False
			Syntax4: SeriesObject.drop([Index],inplace=False/True) 
			Syntax5: SeriesObject.drop([Label Name],inplace=False/True)
			Syntax6: SeriesObject.drop([Index1,Index2,...,Index-n],inplace=False/True)
			Syntax7: SeriesObject.drop([Label1,label2,...,label-n],inplace=False/True)
