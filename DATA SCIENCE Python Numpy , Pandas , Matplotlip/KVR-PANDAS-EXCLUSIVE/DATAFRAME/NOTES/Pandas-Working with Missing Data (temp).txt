=>for Filling missing values, we use
---------------------------------------
1.  fillna():  (Recommended to Use)
---------------------------------------
Syntax1:  df=df.fillna(0) ------will fill all missing values with 0 for entire DataFrame
Syntax2:  df2 = df.fillna(Value)---------will fill all missing values with 'Value' for entire DataFrame
Syntax3:  df.fillna(Value,inplace=True)--------will fill all missing values with 'Value' for entire DataFrame
Syntax4:  df[ColName] = df[ColName].fillna(Value)-----will fill all missing values with One Column
Syntax5:  df[ColName1,ColName2,..] = df[ColName1,ColName2...].fillna(Value)-----will fill all missing values																withMultiple Columns with same value
Syntax6:	 df.fillna(value={'Colname1':'Val','Colname2':'Val2',...'Colname-n':'Val-n'})
