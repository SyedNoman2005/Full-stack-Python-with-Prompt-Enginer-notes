## 🗄️ SQLite vs MySQL

Practice ke liye **SQLite** use kiya hai — zero setup, file-based, turant chalta hai.
Syntax 95% same hai MySQL ke.

Jo differences hain wo `phase3_database/mysql_vs_sqlite.md` me clearly likhe hain.
MySQL ka poora schema `phase3_database/schema_mysql.sql` me hai — jab MySQL install kare, wahi chala dena.

EMS project **dono pe chalta hai** — `phase4_python_db/ems/config.py` me ek line badalni hai bas.
